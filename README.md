# Intro

Binary version for TOON format for machine to machine communication. [TOON specs/docs](https://toonformat.dev/)

Binary TOON (BTOON) is designed for compatible TOON and run by Phoenix Channel of Phoenix web framework.

- [Specification](specs/btoon.md)
- [Executable Livebook walkthrough](specs/btoon.livemd) — a zero-dependency Elixir codec verifying every spec test vector
- TOON text codec: [toon_ex](https://hex.pm/packages/toon_ex) on Hex ([docs](https://toon-ex.hexdocs.pm/))
